# علي أبو طفله

## نبذة عن اللاعب

علي أبو طفله لاعب كرة قدم سعودي، بدأت مسيرتي الرياضية في أكاديمية المطوع، ثم انتقلت إلى نادي الرياض ووقعت عقد هاوٍ مع النادي.

خلال مسيرتي الرياضية شاركت مع عدد من الأندية والأكاديميات، كما ارتبط اسمي بأكاديمية ليدر، والتقيت خلال مسيرتي بعدد من الشخصيات الرياضية والمشاهير.

### المسيرة الرياضية

- أكاديمية المطوع
- نادي الرياض
- أكاديمية ليدر
- كرة القدم السعودية
